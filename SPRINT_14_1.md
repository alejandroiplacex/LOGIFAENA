# Sprint 14.1 — Navegación por teclado

Versión: 1.2.1+1201

## Cambio realizado
La pantalla Configuración ahora permite desplazar el contenido usando:

- Flecha arriba y Flecha abajo.
- Page Up y Page Down.
- Home y End.
- Rueda del mouse y barra de desplazamiento.

Cuando el usuario está escribiendo dentro de un campo de texto, las flechas mantienen su función normal para mover el cursor y no desplazan la página.

## Prueba recomendada
1. Abrir Configuración.
2. Hacer clic en un espacio vacío de la pantalla.
3. Probar Flecha arriba, Flecha abajo, Page Up, Page Down, Home y End.
4. Entrar en un campo de texto y confirmar que las flechas mueven el cursor.
